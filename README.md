## 🚀 Project Overview

The **Task Collaboration Tool** is a Java-based application designed to help users create, manage, assign, and track tasks efficiently.

The application provides a simple platform where users can organize tasks, update their progress, assign tasks to team members, and monitor task status.

---

## ✨ Features

* ➕ **Create Task** – Add new tasks with title, description, priority, and deadline.
* 👤 **Assign Task** – Assign tasks to team members.
* 📋 **View Tasks** – Display all available tasks.
* ✏️ **Update Task** – Modify task details and status.
* 🗑️ **Delete Task** – Remove unwanted tasks.
* 📊 **Task Status** – Track tasks using statuses such as:

  * Pending
  * In Progress
  * Completed
* 🔍 **Search Tasks** – Find tasks based on title or assigned user.
* 💾 **Data Storage** – Store task information for future use.
